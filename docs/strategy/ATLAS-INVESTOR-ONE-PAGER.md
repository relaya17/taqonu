## English (page 1)

**Atlas**  
Trust, memory, evidence and control for AI-native software.

**One sentence.**  
Atlas is the trust, memory, evidence and control layer for AI-native software systems. Arlet Studio is the first environment where that infrastructure is tangible to a developer.

**The problem.**  
AI made writing software cheap. It did not make trusting software cheap. Developers now generate more code than they can reliably verify. Agents can propose work; organizations still lack a system for *what the agent knows, whether it is allowed to act, and whether the result is actually true*.

**Why this is a market, not a slogan.**  
Generation is already priced. Cognition (Devin) raised $2B at $48B in September 2026 (Reuters; ~$900M run-rate). Factory raised $200M at $5B. CodeRabbit raised $143M at $1.5B to govern AI-generated change. LangChain is a $1.25B agent-engineering platform. The open question is not “does AI write code?” It is which layer becomes necessary infrastructure once agents work inside real systems.

**What Atlas is / is not.**

| Atlas is | Atlas is not |
| --- | --- |
| Evidence + memory + authority + verify | A better Cursor |
| Agent ≠ Model. Guardian is deterministic | An autonomous engineer (Devin / Factory) |
| Human remains SoD authority | A vector-DB “memory” product |
| Studio = first proof. Control = later org plane | Ten products (IDE + apps + …) |

**How it decides.**  
Proposal → Guardian (`CONSISTENT` / `CONFLICT` / `UNKNOWN`) → human approval → Apply → Verify → scoped memory. The system can say CONFLICT or UNKNOWN without believing the model.

**Honest status (September 2026).**  
Local path exists: conflict detection, unknown-as-unknown, policy block, human SoD, apply-then-verify, project isolation, audit log.  
Not yet: production proof, paying customers, measured Proof-of-Value, cloud memory sync.

**What we are not asking in a first conversation.**  
Not a priced round. Not a valuation. We want thesis overlap: funds that already believe agents need infrastructure *under* the agent, not another coding workspace.

**Connected applications** (CaseFlow, Vantera, LexStudy, …) are real-world environments where Atlas can show oversight across different agents and policies. They are proof points, not a product zoo. Atlas governs; it does not replace those apps.

## עברית (עמוד 2)

**Atlas**  
שכבת אמת, זיכרון, ראיות ושליטה לתוכנה AI-native.

**משפט אחד.**  
Atlas נבנה כשכבת הראיות, הזיכרון והשליטה שמאפשרת ל-Agent לעבוד על מערכת אמיתית בלי לוותר על אמון ושליטה אנושית. Arlet Studio הוא היישום הראשון שמוכיח את התזה.

**הבעיה.**  
AI מייצר תוכנה מהר יותר ממה שבני אדם יודעים לאמת. השוק כבר לא מחפש עוד כלי כתיבה. הוא מחפש איך לדעת מתי ה-Agent צודק, מתי הוא טועה, מה מותר לו, ומה באמת קרה.

**למה עכשיו.**  
שכבת הייצור (Cursor, Devin, Factory, Replit) כבר מתומחרת בעשרות מיליארדים. שכבת האמון מתחילה להיסחר בנפרד (CodeRabbit לשיפוט על שינוי; LangChain לתשתית Agents; חברות אבטחה לזהות ו-governance). הפער: חיבור של זיכרון + provenance + מצב אפיסטמי + מדיניות + ביצוע מפוקח + אימות.

**מה זה לא.**  
לא “Cursor טוב יותר”. לא מהנדס אוטונומי. לא עוד RAG. לא רשימת פיצ’רים.

**מה קיים / מה לא.**  
קיים מקומית: Guardian דטרמיניסטי, UNKNOWN שלא הופך לביטחון, חסימת סמכות, SoD אנושי, Apply ואז Verify, בידוד פרויקטים, audit.  
לא קיים עדיין: ייצור מוכח, לקוחות משלמים, מדד ערך, סנכרון זיכרון בענן.

**הבקשה בשיחה ראשונה.**  
לא סבב מתומחר. בדיקת חפיפת thesis, ואם יש התאמה — הדגמה של נתיב ההוכחה, לא מצגת פיצ’רים.
