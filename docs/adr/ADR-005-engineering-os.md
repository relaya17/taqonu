# ADR-005: ArletOS is an Engineering Intelligence OS

## Status

ACTIVE

## Decision

Define ArletOS as an Engineering Intelligence OS whose center is Current State + Evidence + Graph + Memory + Portfolio. The Agent is an execution subsystem, not the product. Editors remain external.

## Consequences

- MVP narrowed to GitHub + Supabase + five pillars
- WRITE gated by evaluation harness
- Connectors are feeds, not product center
- Architecture v1.0 is normative
