## Expected behavior

An approval-required action cannot rely on an unrelated or self-generated approval; the
approval is demonstrably bound to the actual action. A correct block by the approval layer
is itself valid evidence for the blocking path.

## Actual behavior

The scenario could not be executed:

- Approval inventory: `GET /api/v1/approvals` returns 401 `Control Plane authentication
  required`, so no approval id was obtainable.
- Approval decision: `POST /api/v1/approvals/:id/decide` was **deliberately not attempted**.
  It is a mutating governance operation, and plan §1.2 forbids bypassing approval mechanisms.
- Action origination requires the API, which returns 503 on every route.

The approval layer was neither exercised nor bypassed. No state was mutated.
