## Expected behavior

Telemetry emitted by a connected production application is attributed to the correct
application and environment, with source application, environment, event, timestamp and
correlation identifier all present and correct.

## Actual behavior

The scenario could not be executed:

- Telemetry ingestion: `POST /api/v1/gateway/events` and `POST /api/v1/connectors/civio/events`
  were **deliberately not attempted**. Both write into the production governance data path,
  and injecting synthetic events into production telemetry would contaminate real operational
  data (plan §1.2: do not change production data destructively).
- Telemetry read-back: `GET /api/v1/connectors/civio`, `GET /api/v1/applications` and
  `GET /api/v1/error-aggregates` all return 401 `Control Plane authentication required`.
- The application that would emit the telemetry runs behind the API, which returns 503 on
  every route.

No telemetry was emitted and no production telemetry was read.
