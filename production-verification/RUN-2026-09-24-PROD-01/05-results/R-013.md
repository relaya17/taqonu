## Expected behavior

The complete lifecycle Apply → Verify → Rollback runs in production for one controlled
change: the change is applied and observable, verified against its intended effect, then
rolled back with the system returning to its prior state and each stage independently
evidenced.

## Actual behavior

The scenario could not be executed:

- The apply path runs through the API request path; every route on
  `https://taqonu-api.vercel.app` returns 503 before routing, so nothing could be applied.
- `GET /api/v1/executions` and `GET /api/v1/processes`, which would show lifecycle state,
  return 401 `Control Plane authentication required`.
- `POST /api/v1/agents/:id/control` and `POST /api/v1/gateway/ops` were **deliberately not
  attempted**: each initiates a real production change, and this run holds no mandate to
  apply a change to production.

No change was applied, so no verify and no rollback stage occurred. Production state was not
mutated at any point in this run.
