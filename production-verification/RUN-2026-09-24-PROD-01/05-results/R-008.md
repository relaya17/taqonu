## Expected behavior

An actual production action creates an audit record that is retrievable and corresponds to
that action — matching actor, action, timestamp, result and correlation identifier.

## Actual behavior

The scenario could not be executed. It has two halves and both are unavailable:

- Producing the action requires the API. Every route on `https://taqonu-api.vercel.app`
  returns 503 before routing, so no auditable production action could be created.
- Retrieving the audit record requires the Control Plane audit endpoints. `GET /api/v1/audit`
  and `GET /api/v1/audit/count` both return 401 `Control Plane authentication required`.

No audit record was created and none was read. The local `.atlas/audit/audit.ndjson` was not
touched, and local audit data was **not** substituted for production audit data.
